# AI E-Commerce Sales Insight System

## Overview
This project is a beginner-friendly AI application for e-commerce. It analyzes product sales data and predicts whether a product is likely to be high-selling or low-selling.

## Features
- View product sales data
- Identify top-selling products
- Detect low-stock products
- Predict product sales performance using machine learning
- Interactive dashboard built with Streamlit

## Tools Used
- Python
- Pandas
- Scikit-learn
- Streamlit

## Business Value
This project helps sellers:
- understand customer demand
- improve product promotion
- make better stock decisions
- identify strong and weak products

```bash
pip install -r requirements.txt
streamlit run app.py

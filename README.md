# AI E-Commerce Sales Insight System

## Overview
This project is an AI-powered web application designed to analyze product sales data and predict whether a product is likely to be high-selling or low-selling. It provides data-driven insights to support better decision-making for e-commerce sellers.

---

## Problem Statement
E-commerce sellers often struggle to identify which products will perform well in the market. Without proper data analysis, it becomes difficult to optimize sales strategies, manage inventory, and target customers effectively.

This project addresses this challenge by applying machine learning techniques to analyze product data and generate actionable insights.

---

## Features
- Product sales data analysis  
- Machine learning-based prediction (high-selling vs low-selling products)  
- Business insights such as:
  - Top-performing products  
  - Low stock alerts  
- Interactive dashboard built using Streamlit  

---

## Technologies Used
- Python  
- Pandas  
- Scikit-learn  
- Streamlit  

---

## How It Works
1. Load product dataset from CSV file  
2. Process and analyze product features (price, views, rating, stock)  
3. Train a machine learning model on historical sales data  
4. Predict whether a product is likely to perform well or not  
5. Display insights and predictions through an interactive dashboard  

---

## Business Value
This system helps:This system helps:
